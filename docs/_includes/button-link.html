{% comment %} Secondary button: an outlined pill with an arrow, for a link to another page. The filled black button stays reserved for the page's main call to action. Parameters: href, label and track (the name under which a click is measured, "secondary_click" by default). Optional: full (true for the full width of its box), describedby (the id of the element that says what the button belongs to) and item (a name sent along with the measured click, for example the package). At full width the outline is drawn inside the button, so it is exactly as high as a filled button next to it. {% endcomment %} {{ include.label }} {% include icon.html name="arrow-right" class="-mr-0.5 size-5" %}
